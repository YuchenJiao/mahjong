# 一桌麻将 · 在线版 2.0

React + TypeScript + Vite前端，Node.js 24后端。支持1–4位真人在线，空座由进阶电脑补齐；保留浏览器本地单人模式。无需账号、付费API或大模型密钥。

## 启动

```bash
npm ci
npm test
npm run build
npm start
```

打开 http://localhost:3000。局域网内其他设备可访问这台电脑的IP和3000端口（需允许防火墙入站）。互联网游玩需部署后端。

开发时分别运行`npm run dev:server`和`npm run dev`，Vite的/api代理指向3000端口。

## 联机流程

1. 点击“联机房间”，填写昵称，创建房间并选择规则。
2. 房主复制邀请链接，其他玩家打开链接后填写昵称、加入房间。也可输入8位房间号。
3. 房主点击“开始牌局”；1–4位真人均可开局，空位由电脑补齐。
4. 四家分别提交同花色换三张、定缺选择。出牌、吃碰杠胡由服务端验证和结算。
5. 断线15秒或操作超时进入电脑托管；原浏览器刷新后重连，点“收回操作”接管。换牌／定缺60秒，行牌45秒。
6. 结束后可复盘四家完整手牌；房主继续下一局，累计座位分数。

房间只在开局前或本局结束后接受新玩家；房主离开后转交仍在房间的玩家。牌局中的离开座位由电脑接手。邀请链接只包含房间号，不含座位凭据；清除浏览器存储会失去原座位的重连凭据。

## 规则与界面

- 川麻：108张、不吃，同花色换三张、定缺、血战到底、一炮多响及独立杠分／流局查叫退税；已胡玩家在结束前仅亮一张和牌，其余手牌保持隐藏。
- 国标：136张、无花牌、吃上家、完整番型计分；8分起胡限制默认开启，开局可关闭，仍保留实际番数和8分底分。
- 两种模式均可关闭番数，按固定底分结算；保留已有番型开关。
- 现代平面牌桌，桌面优先、手机横屏可用；提示、有效进张、建议、音效、本地续局及结束后牌谱回放。
- 服务端管理牌墙和手牌。每位玩家只收到自己的手牌及公开信息；座位凭据仅在浏览器和请求头使用，服务端仅保存凭据哈希。

## 部署

**最省事：Render一个Node Web Service同时运行前后端。** 仓库已有`render.yaml`，默认选择free计算实例。

Vercel或GitHub Pages也可部署前端，但联网房间需要独立Node后端；设置`VITE_ONLINE_API_URL`并在后端配置`ALLOWED_ORIGINS`。GitHub Actions负责测试、构建和可选Pages发布。

完整步骤与免费套餐限制见[部署说明](docs/DEPLOYMENT.md)。API协议见[API文档](docs/API.md)，规则见[引擎说明](docs/RULES_AND_ENGINE.md)，验证范围见[验证记录](docs/VALIDATION.md)。

## 数据与范围

后端使用Node内置SQLite，默认`.data/rooms.sqlite`。持续访问延长房间有效期，无人访问2小时后房间过期。SQLite文件在本地或持久磁盘上可跨进程重启保留；Render免费实例的磁盘是临时的，重启、重新部署或休眠可能丢失房间。当前已部署的托管版使用D1保存房间，和自部署Node版采用相同规则引擎及房间协议。

这是一套邀请房间型麻将项目，没有账号体系、公开匹配、聊天或排位。单人本地模式不依赖联机服务。
