# 电脑与打牌助手 · 2.1

算法是确定性的麻将程序，不使用LLM、远程AI模型或付费推理接口。联网模式的电脑决策和助手建议在Node后端执行；本地单人模式复用同一份TypeScript／Wasm规则与决策代码。

## 可用信息

自己的手牌与副露；四家的当前牌河、公开副露和暗杠数量；历史弃牌顺序；定缺；剩余牌数；已胡时公开的那一张和牌。对手未公开手牌、牌墙顺序与服务端随机种子均不进入PublicView。

物理张数只计算当前牌河、副露、自己的手牌与未重复的公开和牌。历史弃牌提供对手行为线索，不再次计为一张物理牌。例如被碰走的五筒存在于碰牌组，不能又按历史弃牌多加一次。一炮多响的同一和牌也只计一次。旧存档尽可能从公开出牌帧恢复历史。

## 进攻与防守

对每种合法弃牌计算结构向听、还剩多少有效进张，以及番型潜力。国标开启8分限制时，结构听牌进张还要通过常规自摸与可见绝张的合法算分检查；事件番并不能提前当作必然收益。有效进张为0的死听会降级处理。

进阶档对最有希望的3个弃牌候选，再模拟最多3类有效摸牌，并比较下一次弃牌后的进张质量。这是有限搜索，不是穷尽整副牌墙，更不能读取真实牌墙。

对手风险根据副露数量、手牌张数、局面进度、近期弃牌形态、可能的清一色／对对胡方向以及可见牌阻塞进行估计。为候选牌分析顺子、对倒与单吊的剩余组合，川麻缺门牌对相应玩家的胡牌风险为0。历史同牌弃牌只降低风险；国标和川麻都不采用立直麻将的振听逻辑，早先弃过的牌后来仍可能胡。

| 控制项 | 行为 |
|---|---|
| 基础电脑 | 结构向听与真实剩余进张，遵守完整规则；不作防守扣分和额外后续搜索 |
| 标准电脑 | 加入公开牌风险与番型潜力，较轻防守权重 |
| 进阶电脑 | 完整公开信息推断与有限后续进张搜索 |
| 偏进攻助手 | 优先降低有效向听，防守权重较小 |
| 攻守平衡助手 | 通常不为小幅降风险增加向听；晚局手牌较差且有明显威胁才考虑退守 |
| 偏防守助手 | 威胁较强时可牺牲成牌速度，选更低风险的牌 |

电脑难度是房间设置，由房主修改；助手风格是个人偏好，随时调整且不改变房间或倒计时。助手始终使用进阶分析，即使房间电脑选基础档。

## 能力边界

风险和听牌倾向是启发式推断，没有经过统计校准，不能作为准确概率。有限搜索不能保证最优打法，也不能保证必胡或不点炮。回归牌例验证合理的具体行为与完整对局可结束，不等于已经证明胜率提升。
