## 边界

浏览器点击、设备扬声器试听和手机横屏视觉复测尚未完成；接口回归、模拟语音接口测试和生产构建不等于真实浏览器测试。尺寸与网格约束已在源码中落实，但尚未截图核验。中文声音是否可用和具体发音取决于浏览器及系统；首次交互或试听后启用。窄屏允许横向和纵向滚动，没有通过缩小牌面强行塞入一屏。

对手听牌与风险是公开信息上的启发式估计，不是统计校准概率；具体牌例改善不等于已证明总体胜率提升。

此前原ChatGPT Site接口返回“项目不存在”。本版依据用户自部署Render页面的报错截图修复，没有登录或修改其GitHub、Render、Vercel、Pages账户。交付完整源码及历版升级补丁，需推送自己的仓库并重新部署。

本次依据用户截图修复中央重复提示，具体iOS触发机制尚未复现。新结构复用稳定节点，并固定提示槽高度和溢出边界；服务端渲染和模拟动画测试不能证明Safari图形合成问题已经实机消失。没有生成固定女声录音，声音自然程度仍取决于设备提供的实际音色。

本版启动回归在Node.js + jsdom DOM环境运行真实前端入口和实际WebAssembly引擎，未使用真实Chrome/Safari浏览器，不验证像素布局、GPU合成或系统扬声器。延迟加载通过拦截WASM实例化控制，助手所需的structuredClone由Node同名API提供。原始错误复现和修改后回归均已执行。
