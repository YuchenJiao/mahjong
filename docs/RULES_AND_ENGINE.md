# 游戏规则与引擎

React + TypeScript + Vite。1名真人与3名进阶电脑，电脑只依据自身手牌与公开信息决策。现代平面牌桌，电脑优先，支持手机横屏。

## 开发

```bash
npm install
npm run dev
npm test
npm run build
```

游戏可纯前端运行，不需要外部API密钥。可选后端说明见根目录README及docs/API.md。浏览器本地保存当前牌局及最近三局完整回放；可导入导出JSON存档与导出牌谱。更换浏览器或设备时需要手动转移存档。

## 已确认规则

川麻：108张，不吃；同花色换三张，全桌随机顺时针、逆时针、对家交换；换后定缺，优先清缺门；允许一炮多响；三家胡或摸完结束，已胡者退出后续摸打付款。

川麻胡牌展示：牌局仍在进行时，已胡玩家（包括真人）只亮出一张和牌，其余手牌显示牌背；同种牌的其他副本保持隐藏。已公开的碰杠牌组仍显示，胡牌不会自动翻开暗杠。三家胡牌或牌墙耗尽结算后，展示四家完整手牌；结束后的回放也可查看完整手牌。

基础番型：平胡0番，对对胡1番，七对2番，清一色+2番，每根+1番（含杠）。七对与对对胡互斥，龙七对按七对+根。附加番型默认全开且逐项可关：杠上花、杠上炮、抢补杠、海底自摸/点炮各+1番；金钩钓在对对胡基础+1番；带幺九2番；将对3番替代对对胡；天胡/地胡5番替代其他牌型。天胡为交换定缺后庄家首打前胡，地胡为无人碰杠时胡庄家首张弃牌。

封顶3/4/5/6番，默认5番。自摸加底或加番可选，加番参与封顶，加底封顶后+1底。直杠放杠者付2底，补杠其他未胡者各1底，暗杠各2底。杠分独立。流局查花猪（赔所有非花猪玩家封顶分）、查大叫（赔未胡听牌者可胡最高牌型分，不加自摸/事件奖励）、退税。无过手胡、无呼叫转移，抢补杠成功不计该次杠分。无点杠自摸包赔，由未胡者各付。

国标：136张，无花牌，允许吃上家，一家胡牌结算，多人点胡取行牌顺序最近者。完整国标番型与兼计/不计规则，8分起胡限制默认开启，开局可关闭；关闭后不足8分的合法牌型也可胡，仍按实际番种计分。支持普通、七对、十三幺、全不靠/七星不靠、组合龙等胡牌结构。自摸每家8+番种总分，点炮放炮者8+番种总分、其余两家各8；关闭起胡限制仍保留这些8分底分。国标杠无独立即时付款。每局轮庄，每4局换圈风，16局循环。旧存档缺少该开关时默认开启，新存档与续局保留选择。

关闭番数：合法胡牌结构即可胡（川麻仍须符合定缺），点炮放炮者付1底，自摸未胡各1底；取消自摸加底/加番和国标8分底。川麻杠分和退税保留，查花猪/查大叫每笔1底。

自由连续对局，累计分数可负，不因负分停止。川麻首位胡牌者下局坐庄，最初一炮多响时放炮者坐庄，无人胡时保庄。初始庄家为真人，初始累计分0。

## 结构与扩展

- `src/engine/types.ts`：数据与配置。
- `src/engine/rules.ts`：规则注册表和独立计分器。
- `src/engine/game.ts`：对局状态机、抢牌优先级、逐笔付款、回放快照。
- `src/engine/ai.ts`：基于公开观察的向听、有效进张、目标牌型和风险启发式。
- `src/engine/core.ts`：基础牌算法与国标算番适配。
- `src/engine/mcrcore.js`：单文件WebAssembly模块，构建输出已提交，无需玩家安装编译器。

新增规则在注册表中提供牌组、允许操作、多人胡策略及计分函数，并在game.ts提供需要的开局/流局钩子。UI操作按钮根据合法动作生成。AI是启发式牌效与防守策略，不是训练过的职业级模型；无完美安全牌假设。

## 国标算法来源

`vendor/mahjong-algorithm` 来自 [summerinsects/mahjong-algorithm](https://github.com/summerinsects/mahjong-algorithm)，作者Jeff Wang，MIT许可保留在目录中。`vendor/bridge.cpp` 为本项目WebAssembly接口。明暗杠5分作为一明一暗的组合规则支持；无花牌但保留完整番型参考。

如需重编译模块，安装Emscripten 3.1.74后运行 `bash scripts/build-core.sh`。游戏构建无需执行此步骤。
